# ArachnoPhonics

ArachnoPhonics is a spider-themed word guessing game similar to Hangman. Players guess letters to reveal a hidden word while trying to avoid making too many incorrect guesses.

1. Open the ArachnoPhonics project in the sandbox.
2. Make sure `main.py`, `functions.py`, `spiderDraw.py`, and `words.txt` are there.
3. Open `main.py` and click Run.
4. Enter your name and start guessing letters!

- Random word selection from words.txt.
- Players can guess letters to reveal the hidden word.
- Incorrect guesses add body parts to a spider drawing.
- Win and lose conditions.
- Welcome message with the player's name.
- Option to play again after each round.
